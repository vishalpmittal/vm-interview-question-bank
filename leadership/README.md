# Leadership Interview Questions

Question bank for engineering leadership and management interviews. Add files here for questions targeting tech leads, EMs, and senior+ ICs operating at scope.

## Suggested Topics

- People management (hiring, performance, growth, difficult conversations)
- Org & strategy (roadmapping, prioritization, headcount planning)
- Cross-functional influence (working with PM, design, sales, exec)
- Driving change (org transitions, technical migrations, culture shifts)
- Setting direction under ambiguity
- Coaching & mentorship

## File Conventions

- One markdown file per competency area (e.g., `people-management.md`, `strategy.md`).
- Include questions, what to listen for, follow-ups, and red flags.
