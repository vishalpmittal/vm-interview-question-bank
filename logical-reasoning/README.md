# Logical Reasoning Questions

Question bank for logical reasoning, estimation, and analytical problem-solving interviews.

## Suggested Topics

- Fermi estimation / back-of-the-envelope sizing
- Probability and combinatorics puzzles
- Logic puzzles and lateral thinking
- Quantitative reasoning
- Pattern recognition

## File Conventions

- One markdown file per category (e.g., `estimation.md`, `probability-puzzles.md`).
- Include the prompt, expected reasoning approach, common pitfalls, and a worked solution.
