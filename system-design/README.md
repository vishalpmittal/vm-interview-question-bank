# System Design Questions

Question bank for system design interviews. Add files here for design prompts, evaluation rubrics, and worked examples.

## Suggested Topics

- Scalability fundamentals (load balancing, caching, sharding, replication)
- Storage trade-offs (SQL vs NoSQL, consistency models, indexing)
- Distributed systems (CAP theorem, consensus, leader election, queues)
- API design (REST, gRPC, GraphQL, pagination, idempotency)
- Real-time systems (websockets, pub/sub, streaming)
- Common designs (URL shortener, news feed, rate limiter, chat, payments, search)

## File Conventions

- One markdown file per question or topic cluster (e.g., `design-url-shortener.md`).
- Include prompt, clarifying questions, constraints, high-level design, deep dives, and trade-offs.
